# Brainstorm: MVP Focus & Differentiation Strategy

**Date:** January 6, 2026  
**Participants:** Donovan + AI Assistant  
**Topic:** What makes Investio different and what to focus on for MVP

---

## 🎯 The Core Insight

**Investio's killer feature is the multi-tenant model.** Nobody else has it.

- Blossom = Single global social network (Instagram for investors)
- Dub = Copy-trading platform (passive replication)
- **Investio = Infrastructure for investing communities (Shopify/Substack model)**

---

## ✅ Features to KEEP (MVP Core)

| Feature | Why It's Core |
|---------|---------------|
| **Portfolio Tracking** | Foundation - users need to see their holdings |
| **Trading Journal** | Accountability differentiator - track decisions & outcomes |
| **Community Feed** | Multi-tenant value - each community has its own space |
| **AI Coaching** | Unique angle - coach (not signal generator) |
| **Ideas with Outcomes** | Accountability - thesis → result tracking |

---

## ❌ Features to DEFER (Post-MVP)

| Feature | Why Defer |
|---------|-----------|
| Stock picks of the day | Compliance risk, everyone does this poorly |
| Real-time news feed | Can't compete with Bloomberg/Yahoo Finance |
| Audio/podcasts | Heavy content creation burden, not core |
| Memes | Fun but not core value, can add later |
| Course platform | Complex, let tenants link to external resources first |

---

## 🏆 How to Beat Blossom & Dub

| Our Edge | How We Win |
|----------|------------|
| **Tenant-owned communities** | Creators monetize THEIR audience, not ours |
| **Accountability tracking** | Ideas tracked from thesis → outcome (nobody does this well) |
| **Trading journal + AI review** | "Here's what you did right/wrong this month" |
| **Learning cohorts** | Paid courses within communities (Substack for investing) |

---

## 📱 Focused MVP Navigation

```
Dashboard     → Overview of portfolio + activity
Portfolio     → Holdings, transactions, performance
Journal       → Trade log, AI review, win/loss (DIFFERENTIATOR)
Ideas         → Post thesis, track outcomes (ACCOUNTABILITY)
Learn         → Curated content, community guides, AI insights
Community     → Multi-tenant feed
```

---

## 💡 Learning Page Strategy (Keep It Simple)

Instead of building a full course platform:

1. **Curated Links** - Best external resources (Investopedia, etc.)
2. **Community Guides** - Let tenant creators make content
3. **AI Insights** - Personalized based on user's portfolio
4. **Journey Stories** - User-submitted success/failure stories (free content)

**Audio/podcasts = DEFER.** Too heavy to produce and maintain for MVP.

---

## 🎯 Investio's Positioning

> "Show your work, learn from outcomes."

- Blossom = vanity metrics (followers, likes)
- Dub = blind copying (no learning)
- **Investio = accountability + ownership**

---

## 📋 Next Steps Decided

1. Create Sidebar with focused navigation
2. Build Dashboard with portfolio overview
3. Build Journal feature (key differentiator)
4. Build Ideas tracking with outcomes
5. Simple Learn page with curated content

---

## 🗒️ Notes

- Multi-tenancy is foundational - every feature must support it
- Focus on accountability over virality
- AI is a coach, not a signal generator
- Web-first, mobile later
