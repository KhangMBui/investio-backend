# Brainstorm Journal

This folder contains our brainstorming sessions, key decisions, and strategic thinking for Investio.

## Purpose

- Document important discussions and decisions
- Track the evolution of product thinking
- Provide context for future development
- Remember why we made certain choices

## Naming Convention

Files are named: `YYYY-MM-DD-topic-name.md`

Example: `2026-01-06-mvp-focus-and-differentiation.md`

## How to Use

1. After a brainstorming session, create a new dated markdown file
2. Document the discussion, decisions, and reasoning
3. Update this README with a link to the new file
4. Reference these docs when making product decisions
